# Download Syntona

## Executable Binary for MacOS ARM64

### Download DMG file from [GitHub](https://github.com/philburk/syntona-kc/releases).
1. Open the "Assets" and download the Syntona_{?}.dmg file.
2. Open the DMG file and drag Syntona to the Applications folder.

The downloaded version will run a bit faster than the web version. It is also better at managing samples and audio resources.
