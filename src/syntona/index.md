# Syntona - Graphical Editor for JSyn

## What is Syntona?

Syntona is a graphical editor you can use to build and play patches using KSyn unit generators. Syntona patches that contain only KSyn modules can be exported as Korlin or Java source code.

## Web App

Syntona runs as a web app available [HERE](app/).

Note that it is a Beta version.
